# Dubai Community (Backend)
> Community Website for Korean Residents in Dubai
</br>

## 🤖 Project Overview
Design and build the server for the Dubai Community Website.
### Goals
- Follow object-oriented principles
- Prioritize maintainability during development.
- Deploy the server using AWS.

</br>

## 💎 Tech Stack
```
Java17
Springboot
Gradle
Jpa
MySQL
Redis
```

## 📎 Branch Management Strategy </br>
We use Git Flow for branch management.
All branches undergo code review through Pull Requests before merging.</br></br>
<img width="563" alt="git flow" src="https://user-images.githubusercontent.com/31584255/152932423-bcbaee5a-bd21-4b98-82e3-8bc7946c9f61.png" width="800"> </br>
*Source : https://medium.com/@olivier.bossel/git-flow-the-right-way-to-go-f2a65c315818*
- Master: Used for deployment.
- Develop: Only merged when development is fully completed.
- Feature: Used for developing specific features.
- Release: Used to prepare for deployment.
- Hot-Fix: Used for fixing bugs after deployment.
